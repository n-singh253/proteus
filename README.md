# Proteus

Discover the structure of your music.

Proteus is an open-source, local-first music organization engine designed to transform large, unstructured music libraries into cohesive, non-overlapping playlists, without being tied to a single music platform.

## Planned capabilities

- User-guided organization with an exact playlist count or range and optional categories.
- Autonomous organization that discovers useful playlist counts and musical groupings.
- Exactly one playlist assignment for each unique track in the selected collection.
- Local audio and portable file imports/exports, with authorized streaming service adapters where supported and permitted.
- A command-line interface and a locally hosted web interface backed by the same engine.
- Local processing using Rust, Python, and TypeScript, with no required cloud service.

## Status

Early development. The application is not yet implemented or installable. Platform integrations are subject to API availability, authorization, and applicable data-use policies.
